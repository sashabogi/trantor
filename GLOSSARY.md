# Trantor

A cross-agent bus and crew orchestrator: sessions and seats coordinate over a hub, work moves across a board of cards.

## Memory

**Note**:
One memory file an agent session loads as background context for a project.
_Avoid_: memory (alone), memo, lesson, card note

**Lesson**:
A hub-held rule learned from a past crew and injected into seat contracts.
_Avoid_: note, tip

**Pin**:
The link from a note to a code symbol the note describes.
_Avoid_: tag, anchor, reference

**Stale**:
A pinned note whose symbol has been edited since the note was pinned, so the note may no longer be true.
_Avoid_: outdated, expired

**Broken**:
A pinned note whose symbol no longer exists under the pinned name.
_Avoid_: dead, orphaned, missing

**Re-pin**:
Renewing a note's pins after someone has edited the note or confirmed it still holds; the only thing that clears stale or broken.
_Avoid_: refresh, dismiss, acknowledge
