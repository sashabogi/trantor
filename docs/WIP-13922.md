# WIP #13922 — crew tests must never reach the live herdr socket

## Findings (recon at base c3b5681)

- herdr CLI socket resolution order: `HERDR_SOCKET_PATH` env → `$HOME/.config/herdr/herdr.sock`.
  Verified live: `env -i HOME=/tmp/x herdr status` reports `/tmp/x/.config/herdr/herdr.sock`,
  status "not running"; with the pane env it reports `/root/.config/herdr/herdr.sock`, running.
- A seat pane exports `HERDR_SOCKET_PATH`, `HERDR_WORKSPACE_ID`, `HERDR_TAB_ID`, `HERDR_PANE_ID`.
  `test/run.mjs:17` scrubs `DRILL_IDENTITY_VARS` (HERDR_ENV, HERDR_PANE_ID, ...) but NOT
  `HERDR_SOCKET_PATH` — so suite children still NAME the live server even with HOME=tempdir.
  That is the 11-20 incident's path: any suite invoking the real `herdr` binary hits the live
  socket via the inherited `HERDR_SOCKET_PATH`.
- `bin/crew/herdr.mjs` spawns `herdr` via PATH (`call("herdr", args, { env: ctx.env })`), so the
  isolation seams are: PATH (stub binary), HOME, and HERDR_SOCKET_PATH.
- ALL herdr closes funnel through `closeWorkspace`/`closePane` in bin/crew/herdr.mjs
  (createHerdrAdapter → down/prune in bin/crew/state.mjs; prepareWorkspace stale+stray loops;
  replacementPane). One guard covers every close path.
- `test/crew/test-crew-herdr.sh` already runs a stub herdr on PATH, but never FAILS CLOSED: if the
  stub were shadowed/leaked, nothing aborts.
- `bin/drill-seams.mjs` / `bin/drill-surface.mjs` symlink the REAL socket into temp homes — those
  are operator drills, not npm test suites; out of scope here but the fail-closed check must be
  realpath-aware so a symlinked real socket trips it.

## Plan

1. Harness: `test/lib/herdr-stub.mjs` — resolve real socket (runner-captured
   TRANTOR_TEST_HERDR_REAL_SOCK → HERDR_SOCKET_PATH → `herdr status` → HOME default), resolve the
   socket an env WOULD use, abort before any herdr call on match (realpath-aware). run.mjs captures
   the real socket BEFORE scrubbing; DRILL_IDENTITY_VARS gains HERDR_SOCKET_PATH/WORKSPACE_ID/TAB_ID.
   test-crew-herdr.sh gets the same fail-closed wiring.
2. Guard in bin/crew/herdr.mjs: closeWorkspace/closePane refuse the caller's own workspace/pane
   (HERDR_WORKSPACE_ID, HERDR_PANE_ID prefix/exact) with a plain reason, unless
   TRANTOR_CLOSE_OWN_WORKSPACE=1; prepareWorkspace keeps the row when a stale close was refused.
3. Tests: fail-closed trips (real path + symlink-to-real), stub env passes; own-workspace close
   refused (override works); own pane refused, sibling pane in same workspace allowed; stale
   cleanup still closes a truly stale workspace in the stub.
