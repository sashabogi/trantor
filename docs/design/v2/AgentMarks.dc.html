PROPOSAL · AGENT MARKS IN MOTION · NOTHING HERE IS BUILT YET

The seat tab shows the state in the vendor's own mark: it moves when the agent works, waits, needs you or sleeps

Live CSS on the crisp marks the app already ships. The marks are never redrawn or recoloured; only a ring, a badge and a transform go around them. Hover a cell to replay the one-time entrances (the nudge and the check). Colours are Trantor's own: working accent, needs you warn, waiting proposal, ready ok, sleeping faint.

E · RULES

CSS only, and only transform, opacity and filter animate. The animations pause when the window is hidden. A state change cross-fades over 180ms. Sizes: 20px seat tabs, 16px chat header and tiles, 28px hover card. The monogram stands in only when a harness has no vendor mark.
