F · HOW IT IS BUILT

One hand-drawn character as inline SVG: helmet, ear discs, antenna and light, visor, mark slot, body, hands and keyboard as separate parts. CSS keyframes move only transform and opacity, so it stays on the GPU and costs nothing while a seat is still. The same definition serves every vendor: only the visor colour and the mark change (the marks are the ones the app already ships). A state change cross-fades over 180ms, the animations pause when the window is hidden, and reduced motion gets the static poses above. A few KB per character, no generated video or GIF.
